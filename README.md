# Search Pattern

A checklist cue tool for radiology search patterns. Pick a modality and study, then step through each view and structure with the keyboard. Items can be read aloud.

- Open `index.html` in a browser, or use the hosted page.
- Keys: Space or Right arrow = next item, Left arrow = back, Down = next view, Up = previous view.
- Paste a study name into the match box to load the best-matching study.
- Edit templates with the Edit button. Edits are saved in your own browser; use Export and Import to move them.
- Everything runs in the browser. No patient data is entered or stored.
